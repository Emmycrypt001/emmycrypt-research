# Project 007 — Nigeria Education Data Entry, Cleaning & Excel Analysis

## Overview
A practical Microsoft Excel portfolio project demonstrating data entry, spreadsheet structuring, data cleaning, validation, formula-driven computation, reporting, and visualization using a structured Nigeria education dataset.

## Workbook structure
- **README** — project documentation and methodology
- **SOURCE_DATA** — preserved source layer
- **DATA_ENTRY** — structured data-entry workflow
- **DATA_CLEANING** — text cleaning, missing-value checks, duplicate checks, numeric checks, and review flags
- **DATA_VALIDATION** — controlled input with dropdowns and numeric/percentage restrictions
- **COMPUTATIONS** — formula-driven metrics
- **SUMMARY** — key reporting metrics
- **CHARTS** — visual reporting

## Excel skills demonstrated
- Data entry and spreadsheet structuring
- Excel Tables
- TRIM and PROPER
- Missing-value and duplicate checks
- ISNUMBER validation
- Data Validation and dropdown lists
- SUM, AVERAGE, MIN, MINIFS, MAX, COUNT, COUNTA, COUNTIF, SUMIF, IF, IFERROR, XLOOKUP
- Sorting and filtering
- Conditional formatting
- Freeze panes
- Summary reporting and charts

## Methodology
1. Preserve the source layer separately.
2. Structure records into consistent spreadsheet fields.
3. Clean and standardize working data.
4. Flag missing or unusual values instead of inventing replacements.
5. Apply data-validation controls.
6. Calculate key metrics with Excel formulas.
7. Present results in a summary sheet and charts.

## Data quality note
This project is primarily a demonstration of spreadsheet and data-handling skills. Values should be checked against the original public source before use for official reporting or policy conclusions.
